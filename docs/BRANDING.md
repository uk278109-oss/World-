# WORLD Branding

The supplied WORLD artwork is preserved as three production assets:

- `/public/world-app-icon.jpg` — app icon artwork
- `/public/world-symbol.jpg` — W + globe symbol used on launch/splash
- `/public/world-wordmark.jpg` — WORLD wordmark used in the app header
- `/public/icon.svg` — SVG wrapper using the supplied app-icon artwork for favicon/PWA compatibility

## Launch animation

The app shows the supplied W + globe symbol on a pure-black launch screen, then reveals the WORLD wordmark and `BE THERE` before transitioning into the app. The animation respects `prefers-reduced-motion`.
