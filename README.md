# WORLD — Production Candidate

WORLD is a real-time social discovery app built with React/Vite and Appwrite.

## Appwrite
- Endpoint: https://nyc.cloud.appwrite.io/v1
- Project ID: 6aa5127e001ea31b0f77

- Media bucket: 6aaaa1b70013c346455e

## Deploy
1. Upload this project to GitHub.
2. Import the repository into Vercel.
3. Build command: `npm run build`
4. Output directory: `dist`

Keep the Appwrite Web platform hostname registered for the Vercel domain.
