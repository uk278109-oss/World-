# WORLD — Be There.

React + Vite Progressive Web App foundation for WORLD.

## Stack
- React + Vite
- Appwrite client SDK
- PWA manifest
- Lucide professional SVG icons
- Mobile-first dark UI

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Appwrite
Edit `src/config/appwrite.js` with the final database/table IDs after confirming them in the existing WORLD Appwrite project.

The Appwrite endpoint and project ID are already set to the current WORLD project. Never place server secrets in this frontend.
