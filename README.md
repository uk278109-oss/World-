# WORLD — Complete Replacement

WORLD is a global real-time activity discovery PWA powered by Appwrite.

## Appwrite
- Endpoint: https://nyc.cloud.appwrite.io/v1
- Project ID: 6aa5127e001ea31b0f77
- Database ID: 6aaa2edb002d5a668746
- Media bucket: 6aaaa1b70013c346455e

## Included
- Email/password authentication
- WORLD NOW / FLOW / SCENES / TALK / SPACE navigation
- Create, join, react and comment on Moments
- Profile, edit profile and user Moments
- Follow/unfollow support
- Activity feed
- Moment search
- Auto-expiry filtering for active Moments
- Responsive dark WORLD UI with SVG icons

## Run
npm install
npm run dev

## Deploy
Upload/replace the project files in the existing GitHub repository and deploy through Vercel.
