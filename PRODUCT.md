# WORLD Product Lock

WORLD is a global real-time social discovery platform.

Core loop:
OPEN WORLD → NOW → BE THERE → WATCH/TALK/PULSE → MEET PEOPLE → CONNECT/SUBSCRIBE → SCENE → SPARK → SIGNAL → RETURN

Formats:
- FLASH: 5–30 seconds
- DROP: 30 seconds–5 minutes
- NOW: temporary live activity
- SCENE: place/event/activity

Navigation:
NOW, FLOW, SCENES, TALK, SPACE
Main action: SPARK
